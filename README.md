## 安装与更新

仅需将以下 **2 个文件**放入 Capture 自动加载目录。`*-runtime.zip` 解压后直接得到这两个文件；完整开发分享包则位于 `capAutoLoad` 子目录：

| 运行文件 | 作用 |
| --- | --- |
| `OrCADQuickTools.tcl` | 合并主程序、XLSX 写入、跨页图形替换、鼠标控制；包含 11 个快捷键及中文帮助/菜单 |
| `OrCADWheelZoom.exe` | 滚轮缩放、右键平移，以及 Alt+S 原生 Signals 菜单执行辅助程序 |

Capture 16.6 常见安装位置：

```text
C:\Cadence\Cadence_SPB_16.6\tools\capture\tclscripts\capAutoLoad\
```

1. 先备份原理图和原有工具文件，保存设计并关闭 Capture。
2. 复制上述 2 个文件。**不要把 src、source、历史备份或 test_*.tcl 放进自动加载目录**，测试文件会模拟/覆盖接口。
3. 从旧五文件版升级时，把旧的 `OrCADPinNetXlsx.tcl`、`OrCADOffPageToggle.tcl`、`OrCADWheelZoom.tcl` 及本工具 `before*.tcl` 备份移出自动加载目录；不要删除 Capture 自带脚本。
4. 重启 Capture，打开原理图，按 `Alt+F1` 检查中文帮助。
5. 如之前关闭过鼠标导航，从 `Accessories → 快捷工具 → 鼠标导航开关（滚轮缩放/右键平移）` 开启。

EXE 缺失时，鼠标导航和 Alt+S 不可用，其余键盘功能仍可使用。Alt+S 与鼠标导航开关独立：关闭滚轮/平移不影响 Signals 操作。更新必须同时复制两个文件并重启 Capture，不要混用旧 TCL/EXE。

同一会话重新装入新版 Tcl 时保留已经注册的动作，避免反复注销/注册造成 Capture 16.6 快捷键失效。若改变快捷键配置，或已在旧版会话内多次重新注册，请保存设计后重启；不要依赖热加载恢复旧的快捷键绑定。

源码下载不含编译后的 exe 时，在源码目录执行 `.\build_wheel_zoom.ps1`，再复制生成的 exe。需要 Windows .NET Framework 4 编译器；不需要 Excel 或 AutoHotkey。若系统拦截下载的文件，先核对文件来源及校验值，再按单位安全规范处理，不建议全局关闭安全策略。

## 使用要点

### NC 标记

框选一个或多个器件：`Alt+F2` 将 `10K` 改为 `NC,10K`；`Alt+F3` 去掉开头的标记。只处理器件，不修改选中的导线和文字。此功能是 Value 标记，不会自动改变 BOM 导出规则。

### 新增器件位号修正

在当前页选中新增器件按 `Alt+R`。例如 Page Number 为 3，已有 `R301 / R302`，新增 `R3002` 可改为 `R303`。已在当前页号段中的所选器件保持不变；优先续编，不够时寻找空号。不要把此功能当作全页重新排序。

### 跨页连接符图形切换

选中连接符本体后按 `Alt+F5`，再选中同一符号可反向切换。支持多选，支持配对图形 `OFFPAGELEFT-L ↔ OFFPAGELEFT-R` 及 `OFFPAGELEFT/L ↔ OFFPAGELEFT/R`。

首次使用也直接执行，不再弹出备份/继续确认。操作说明和备份提醒集中在 `Alt+F1`；实际失败仍会提示。

只改变输入/输出图形表示，不改网络名、器件位号或器件引脚电气类型，不刷新跨页引用页码。找不到同库配对图形时，会提示先放置另一种符号；不擅自替换自定义符号。首次请在设计副本上测试。若报恢复失败，不保存该测试副本，从备份重新打开。

### 引脚—网络表导出

选中一个或多个器件按 `Alt+F6`，选择保存位置即可生成 `.xlsx`，WPS 可以打开，无需 Microsoft Excel。

器件按区块显示，页名、位号、Value 只在该器件信息行显示一次；明细保留 **Pin Number / Pin Name / Net Name / Connection** 四列。每个器件的引脚按自然数字顺序排序：`1、2、3……10、11`，未连接项标红。器件区块顺序不是额外的位号排序承诺。

### 标题栏同步

`Alt+F7` 输入统一项目名后，更新全部标题栏的 `Doc`，并把每页 `Title` 同步为真实 Page Name。不是重命名工程文件，也不重命名页面。适用于当前所用标题栏的这两个字段；自定义标题栏字段需另行适配。

### 页码与位号

- `Alt+F8`：仅重排当前页。
- `Alt+F9`：用现有标题栏 Page Number 重排全部位号，不改页码。
- `Alt+F10`：仅重置 Page Number / Page Count，不改器件位号、不重命名页面。
- 同时重置页码和位号时，**先 Alt+F10，检查页码；再 Alt+F9，检查位号**。

位号按从左到右、从上到下的位置顺序规划；每页、每种前缀独立编号。第 3 页为 `R301–R399 / C301–C399`，第 23 页为 `Q2301–Q2399`。每页同一前缀最多 99 个位号，多单元器件保持共用位号。

页名采用自然排序：`P2 < P10`、`2 < 10`；无数字页名按名称顺序。此排序不是直接读取项目树手动排列。页面标题 Title 不用于代替真实页名；位号号段以 Page Number 为准。

### 鼠标导航

在当前可见原理图绘图区直接滚轮缩放、按住右键拖动画布。点击其他软件后，只需把鼠标移回绘图区即可继续，不要求先点左键，也不强制改变键盘焦点。

只处理真实命中的绘图区，不搜索被其他软件遮挡的画布。项目树、属性表、弹窗和其他软件区域保持原操作；按 Ctrl / Shift / Alt 等修饰键时不启动映射。拖动途中移出绘图区、按 Escape、其他鼠标键或前台窗口改变，会终止该次平移。

平移受原理图原生可滚动范围限制：整页完全显示时无可平移空间；一个方向不能滚动，不影响另一个方向。鼠标导航不移动器件，不占用新的快捷键。

右键单击在松开后由 Windows 原生输入回放，而不是向 Capture 手工投递坐标；只补发带自身标记的右键按下/松开，不移动鼠标、不发送左键或键盘输入。指针离开原处、换页/切换窗口、出现弹窗或新的鼠标操作时取消待回放点击，避免误点其他位置。屏幕边缘的菜单自动避让仍由 Windows/Capture 决定，不强制菜单始终向右展开。右键拖动不使用此回放路径。

首次默认开启，之后记住开关；随 Capture 启动/退出，不安装 Windows 开机启动项。

运行中短暂状态读写失败不再直接关闭功能；辅助程序心跳连续异常时自动停止旧实例、重新启动监听。重启至少间隔 10 秒，每分钟最多 3 次，避免反复启动；明确从菜单关闭后不会自动恢复开启。控制器状态过期时暂时放行原生鼠标操作，恢复有效状态后继续映射。不会重启 Capture 或修改原理图。

### Signals 网络导航（Alt+S）

在原理图中单击选中**一根网络导线**，鼠标停留在该导线上，按 `Alt+S`。菜单执行前保持鼠标位置、不切换窗口；Signals 执行后的菜单收尾允许移动和悬停。0.20 不再等待特定按键松开，启动时已按住的快捷键重复/首次松开不算新操作；不要连续重按或开始新操作。工具短暂打开原生右键菜单，识别可用的 **Signals** 菜单项并执行其默认操作，打开原有 Signals 列表供跳转使用。仅选网络名文字、器件、跨页符号、总线或多选时不执行。此功能不是编辑网络属性，不修改网络名称、连接或器件。

**自定义绑定**：配置入口为 `src/OrCADQuickTools.core.tcl` 中的 `::OrCADQuickTools::ActionDefinitions`；改动后生成合并 TCL。0.20 EXE 不再写死等待 Alt/S，可配合 TCL 更换快捷键，但须避开 Capture 或其他工具的绑定冲突，实际键名格式与版本支持需验证。不要对所有代码做不受控的全局替换；帮助文字可对应调整。已经将 TCL 改为 Ctrl+F2 的用户可保留自己的 TCL，先单独更新为 0.20 EXE 并重启测试，不必把自定义绑定改回 Alt+S。用户已确认 0.20 在 Capture 17.4 中使用 Ctrl+F2 执行 Signals 导航成功；其他组合、版本或环境仍需验证。

直接调用本地命令 `14844` 未能建立网络上下文，用户反馈手动右键 Signals 正常。0.17 修正辅助程序启动阻塞 Capture 的问题：先建立不可见的消息循环，等待 Tcl 确认启动调用已返回，再打开右键菜单；启动握手超时不会发送鼠标输入。同时兼容 Capture 菜单根对象不支持名称读取的情况，通过 Windows MSAA 识别真正的菜单项，不依赖固定窗口类或菜单坐标。

仅检查本次新出现、属于目标 Capture 所有权链或当前绘图区线程的窗口；菜单项须名为 Signals、类型为菜单项、可见且可用，执行前重查状态。失败不盲发 14844，不模拟左键、键盘或移动指针。辅助程序执行一次后，Tcl 只读取结果，不再重复调用命令。

**0.20 用户验证（2026-10-10）：Capture 17.4 与 Ctrl+F2 自定义绑定已验证成功。** 此反馈针对 Signals 操作及本次修复，不代表所有功能和所有环境均已验证。

**0.17 已在本机 Capture 16.6 中实测：连续选择三个不同网络，Alt+S 自动执行 Signals，列表及 Capture 查找日志均对应当前网络。** 最终构建也已单独复测。未修改或保存原理图。其他版本及不同设计仍需验证；首次请连续选择两个不同网络检查列表。程序日志中的 `pane result not verified` 表示代码没有自动读取列表结果，不代表操作失败；上述实测是通过观察真实界面及 Capture 查找日志确认。若仍只出现菜单或报错，请提供下方两个 Signals 日志。

## 安全与故障排查

修改设计前先备份。位号重排可能影响 PCB / ECO / 外部网表；不要在唯一原稿上验证。页码和批量位号操作有写入校验及失败恢复，但不能保证恢复已损坏的设计。复用层次原理图会停止自动重排，避免错误修改 occurrence 数据。

| 功能 | 诊断位置 |
| --- | --- |
| 主快捷键、标题栏、页码/位号 | Capture Command Window |
| XLSX 导出失败 | `%TEMP%\OrCADPinNetExport.log` |
| 跨页图形替换 | `%TEMP%\OrCADOffPageToggle.log` |
| 鼠标导航 | `%TEMP%\OrCADWheelZoom-<Capture进程号>.log` |
| 鼠标导航控制器（开关、异常、自动恢复原因） | `%TEMP%\OrCADWheelZoom-<Capture进程号>-controller.log` |
| 鼠标导航开关记录 | `%LOCALAPPDATA%\OrCADQuickTools\wheel-zoom.enabled` |
| Signals 网络导航 | `%TEMP%\OrCADSignalsNavigation.log`、`%TEMP%\OrCADSignalsNavigation-native.log` 及 Capture Command Window |

若鼠标功能关闭，先检查菜单开关；若装入后没变化，检查 2 个文件是否同目录、旧模块是否移出，然后重启。持续使用后再次失效时，请提供同一 Capture 进程的鼠标日志及控制器日志，以区分手动关闭、读写失败、心跳超时和监听异常。错误反馈请附具体版本、操作步骤和脱敏日志，不要公开真实工程数据。

## CPU 与内存占用

- Tcl 快捷工具随 Capture 加载，NC 标记、位号调整、标题栏同步、图形切换及导出等主要在调用时执行；批量处理时临时占用取决于设计大小。
- 滚轮缩放和右键平移开启后，鼠标辅助程序常驻。当前控制器约每 400 毫秒检查一次，辅助程序有 100 毫秒状态检查和 16 毫秒拖动/点击处理计时器；空闲时也有少量开销，不能视为零占用。
- `Alt+S` 的 Signals 辅助调用是短时操作，完成或超时后退出；关闭鼠标导航开关不影响 `Alt+S`。单次调用使用临时只读输入监听，区分悬停、初始快捷键释放与新操作；仅临时保存按住状态，不拦截输入、不记录按键内容，调用结束即移除，异常情况下最多监听 10 秒，不新增常驻监听。
- 没有提供固定的 CPU 百分比或内存数值：实际占用应在自己的电脑上测量，文件大小不等于运行内存。关闭菜单中的鼠标导航可停止这部分常驻辅助进程及心跳，其余快捷操作仍可用。
